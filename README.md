# Marwadi Laravel Website

Laravel website for Marwadi Finance broker, using the client-supplied bull logo, charcoal/gold/warm-white styling, original artwork and the agreed page structure.

Open http://127.0.0.1:8000.

Run: `php artisan serve --host=127.0.0.1 --port=8000`

See [PROJECT.md](PROJECT.md) for page scope, contact-address configuration, forms, market data, source-asset limitations and verification.

The public Login button now opens `/login`, the integrated admin/client sign-in. Signed-in users enter `/workspace`; the public homepage remains `/`. See [Workspace integration](documents/Workspace-Integration.md) for the imported records and test results.
